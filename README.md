\# Editorial Gallery — WordPress Store



Editorial Gallery is a fictional home-objects ecommerce demo built with WordPress and WooCommerce.



\## Technologies

\- WordPress

\- WooCommerce

\- Kadence Theme

\- Elementor Free

\- eSewa WooCommerce Plugin (Sandbox mode)



\## Features

\- Homepage and About page

\- Shop and four product categories

\- Four demo product pages

\- Shopping cart and quantity updates

\- WooCommerce checkout

\- eSewa sandbox payment testing



\## Important

\- Products, prices and descriptions are fictional.

\- eSewa is configured for sandbox testing only.

\- No real payments should be made.

\- The local wp-config.php file and database backup are not included in this repository for security.

\- Running the website requires a local WordPress setup and a separately provided database backup.



\## Local development

The original development environment uses XAMPP and a local WordPress installation.
